# 昌大专属

这一部分是写给南昌大学同学的场景化入口。

但它当前的定位需要先说清楚：**这里不是一个已经完整成型的“资源库”，而是一个正在持续补全的校内经验入口。**

我们更希望它先做到两件事：

1. 帮你知道哪些问题值得优先关注
2. 给你一个不容易迷路的起读入口

而不是制造“这里已经什么都有了”的假象。

---

## 这里主要在覆盖什么

目前这部分主要围绕 3 类校园议题展开：

### 1. 学业发展

包括：

- [培养方案全解](./academic-development/program-guide.md)
- [学分绩点体系](./academic-development/credits-and-gpa.md)
- [特色实验班](./academic-development/experimental-classes.md)
- 转专业、保研、考研等专题入口

**适合谁：** 想先搞清楚学校制度、培养路径和一些关键节点的人。

### 2. 资源与机会

包括：

- [社团与组织：计算机相关](./clubs-and-organizations/cs.md)

**适合谁：** 想了解校内有哪些组织、社群和尝试空间的人。

### 3. 校园生活

包括：

- [通识课程体系](./campus-life/general-education-courses.md)
- [体育与体测](./campus-life/pe-and-fitness-tests.md)
- [新生军训](./campus-life/military-training.md)

**适合谁：** 刚入学或还不熟悉校园运行方式的人。

## 建议你怎么使用这一部分

### 如果你是新生

建议先看：

1. [培养方案全解](./academic-development/program-guide.md)
2. [学分绩点体系](./academic-development/credits-and-gpa.md)
3. [通识课程体系](./campus-life/general-education-courses.md)

### 如果你在思考学业路径

建议优先关注：

- [特色实验班](./academic-development/experimental-classes.md)
- 转专业相关入口
- 保研 / 考研相关入口

### 如果你还不知道要不要深入这一区

先记住一个原则：**只有当问题明确是“南昌大学场景特有”时，再优先来这里找答案。**

如果你现在卡住的是更普适的成长、决策、学习问题，建议先回到：

- [首页](../index.md)
- [全站导览与官方推荐路径](../growth-general-course/00-before-we-start/overview.md)
- [核心原则：构建你的个人决策系统](../growth-general-course/01-the-zero-course/the-core.md)
