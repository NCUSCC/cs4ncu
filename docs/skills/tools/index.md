# 工具与系统导览

这个模块不是单纯罗列软件，而是关注：**哪些工具和系统能力，能真实降低你在大学里的摩擦成本。**

它适合这样的人：

- 经常被电脑、文件、环境配置、资料整理这些事情卡住
- 明明花了很多时间在“折腾”，但没有形成稳定工作流
- 想建立一套更长期可复用的数字能力，而不是只会临时凑合

---

## 这个模块在解决什么问题

很多人会把工具理解成“会不会用某个软件”，但更关键的是：

- 你是否理解数字环境的基本逻辑
- 你是否有能力管理文件、资料、任务和版本
- 你是否能让工具为自己节省时间，而不是制造新的负担

所以这里讲的是“工具 + 系统”。工具是器，系统是你使用它们的方式。

## 建议先读什么

### 1. 数字素养

适合刚开始建立数字基础的人。建议优先看：

- [电脑认知](./literacy/computer-basics.md)
- [高效打字](./literacy/typing.md)
- [网络工具](./literacy/network-proxy.md)
- [版本选择](./literacy/version-control.md)

**你能获得什么：** 对自己的数字环境更有掌控感，少被基础问题反复卡住。

### 2. 信息管理

适合资料越来越多、任务越来越杂的人。建议优先看：

- [云笔记](./pkm/cloud-notes.md)
- [协作文档](./pkm/collaboration-docs.md)
- [任务管理](./pkm/task-management.md)

**你能获得什么：** 把信息和任务放回一个更清晰、可持续维护的结构里。

### 3. 生产力工具

适合已经有基础，希望进一步扩展能力边界的人。可按需选择：

- [Git](./pro/git.md)
- [Linux](./pro/linux.md)
- [LaTeX](./pro/latex.md)
- [Prompt Engineering](./pro/prompt-engineering.md)
- [Docker](./pro/docker.md)
- [Premiere Pro](./pro/premiere.md)

**你能获得什么：** 根据自己的方向需要，逐步积累更强的“可迁移工具力”。

### 4. VS Code 指南

适合希望把常用开发/写作环境调顺的人。入口：

- [导览与配置](./vscode/index.md)
- [插件推荐](./vscode/extensions.md)
