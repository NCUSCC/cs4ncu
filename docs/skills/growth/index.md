# 成长与规划导览

这个模块讨论的是那些**不会立刻出现在考试里，却会持续影响你大学四年乃至更久的长期议题**。

它适合这样的人：

- 不想只把大学理解成“上课 + 考试”
- 开始意识到财务、健康、机会选择这些问题迟早要自己面对
- 想让自己的成长更可持续，而不是一阵热血、一阵崩盘

---

## 这个模块在解决什么问题

很多大学生的问题，不是不会努力，而是没有把“长期运行”当作一个系统来对待。

比如：

- 你会不会管理自己的钱
- 你有没有基本的身体维护意识
- 你如何识别值得抓住的机会
- 你如何把短期选择放回更长的路径里看

这个模块要补的，就是这些容易被忽视、却迟早会追上你的现实问题。

---

## 建议先读什么

### 1. 财务管理

适合想先建立基础生活掌控感的人。建议优先看：

- [财商启蒙](./finance/financial-literacy.md)
- [聪明消费](./finance/smart-spending.md)

**你能获得什么：** 对花钱、储蓄、消费判断更有意识，避免长期被无计划支出拖着走。

### 2. 身体健康

入口：

- [健康管理](./health/healthy-management.md)

**适合谁：** 常常熬夜、透支、忽视身体信号，直到状态明显下滑的人。

**你能获得什么：** 开始把健康当作成长能力的一部分，而不是“有空再说”。

### 3. 机遇探索

适合想理解“我还可以尝试什么”的人。建议按需阅读：

- [信息差](./opportunity/information-gap.md)
- [开源之旅](./opportunity/open-source-journey.md)
- [实验班解读](./opportunity/innovation-classes.md)
- [职业规划](./opportunity/career-planning.md)

**你能获得什么：** 更现实地看待机会，不盲目追风口，也不在信息差里长期被动。
