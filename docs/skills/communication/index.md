# 沟通与协作导览

这个模块关注的不是“会说话”这么简单，而是**你如何与他人建立有效连接、推进合作，并在关系中减少无效内耗**。

很多大学里的关键机会，最后都不只取决于你会不会做事，也取决于你能不能：

- 把自己的想法说清楚
- 和别人顺畅协作
- 处理误解、冲突与边界问题
- 在关系里建立长期可信度

---

## 这个模块在解决什么问题

当我们说“沟通能力”时，真正包含的通常是 3 件事：

1. **表达**：把意思说明白，而不是让对方猜
2. **连接**：建立健康、稳定、互相尊重的关系
3. **协作**：在共同目标下推进事情，而不是各做各的

这也是为什么这个模块不只讲技巧，还会涉及关系、团队和冲突。

---

## 建议先读什么

### 1. [沟通技巧](./skills/communication.md)

**适合谁：** 想把话说清楚、减少误解、提升日常表达效果的人。

**你能获得什么：** 对沟通这件事建立一个更基础的认识，避免“明明说了，但没有真的传达”。

### 2. [构建人际关系网](./skills/network-of-relationships.md)

**适合谁：** 不想把关系理解成“混圈子”，但又知道人际支持系统很重要的人。

**你能获得什么：** 更现实地理解关系的建立、维护与互相支持，而不是把社交看成表演。

### 3. [团队协作](./teamwork/teamwork.md)

**适合谁：** 参与社团、项目、课程作业或开源协作时，常常感到配合混乱的人。

**你能获得什么：** 更清楚地理解团队里角色、配合与推进的基本逻辑。

### 4. [人际矛盾处理](./skills/dealing-conflicts.md)

**适合谁：** 容易在关系冲突里回避、爆炸或长期内耗的人。

**你能获得什么：** 学会识别矛盾类型，并尝试用更稳定的方式处理边界和分歧。
