# 学会学习导览

这个模块关注的不是“多学一点”，而是**把学习这件事本身重新搭起来**。

如果你经常遇到这些情况，这一部分大概率适合你：

- 明明花了很多时间，却总觉得没学进去
- 资料越看越多，反而越来越乱
- 学一阵就很疲惫，难以稳定持续
- 知道努力重要，但不知道怎样建立自己的学习系统

---

## 这个模块在解决什么问题

大学里的一个常见误区是：以为只要更努力，学习问题就会自然消失。

但很多时候，真正卡住你的不是意志力，而是学习系统本身：

- 你如何获取信息
- 你如何组织理解
- 你如何管理注意力与精力
- 你如何复盘并调整自己的方法

所以这个模块更像一个“学习操作系统”区，帮助你把学习从临时冲刺，变成可以长期运行的能力。

---

## 建议先读什么

### 1. [元学习](./meta/meta-learning.md)

**适合谁：** 觉得自己一直在学，但不确定有没有学对的人。

**你能获得什么：** 建立“规划 → 学习 → 反思 → 调整”的学习循环，开始把自己当作学习系统的设计者，而不只是执行者。

### 2. [信息输入](./intake/information-intake.md)

**适合谁：** 经常被信息洪流淹没，不知道什么该看、什么不该看的人。

**你能获得什么：** 更清楚地理解自己应该如何筛选资料、控制输入噪音、避免被低质量信息牵着走。

### 3. [知识内化](./consolidation/knowledge-consolidation.md)

**适合谁：** 看了很多内容，却总觉得记不住、讲不出、用不上的人。

**你能获得什么：** 把“看过”逐步变成“理解过、整理过、能复述、能调用”。

### 4. [精力管理](./energy/energy-management.md)

**适合谁：** 想学很多，但常常在分心、疲惫、任务堆积中失速的人。

**你能获得什么：** 识别精力被什么消耗，并逐步建立更稳的任务安排和节奏感。
