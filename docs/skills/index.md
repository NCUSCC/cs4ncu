# 本部分导览

《第零点五课堂》是本站的“能力模块区”。

如果说 [本科生通识第零课](../growth-general-course/01-the-zero-course/index.md) 更像一条核心主线，帮助你建立“向内看 → 向外看 → 去行动”的决策框架，那么《第零点五课堂》更像一个按主题展开的工具箱：你可以在这里补齐那些**本应更早学会、却常常没人系统讲清楚的底层能力**。

---

## 为什么叫《第零点五课堂》？

在大学里，我们习惯于把内容分成“第一课堂”和“第二课堂”。但我们发现，还有一类知识卡在两者之间：

- 它不属于标准专业课
- 它也不只是课外活动经验
- 它往往比具体专业技能更基础
- 它会直接决定你能不能更稳地学习、合作、行动和成长

我们把这部分内容称为**《第零点五课堂》**。

“零点五”的意思，不是它不重要，恰恰相反：**它是很多事情正式展开之前，就应该先拥有的一批前置能力。**

---

## 这一部分适合谁

如果你现在的状态更像下面这些描述，这一部分会比“继续盲目刷经验贴”更适合你：

- 你已经知道自己要努力，但不知道先补哪种底层能力
- 你不是完全没有方向，而是卡在“学不动、做不稳、配合不好、工具太乱”这些具体问题上
- 你不想只看宏大叙事，而是想按主题补齐一部分实际可用的能力

---

## 这部分现在有哪些模块

### 1. [认知与心智](./mindset/index.md)

**适合谁：** 想减少内耗、看清思维陷阱、建立更稳判断底盘的人。

**你能获得什么：** 对偏差、定式、心理状态与基本心智模型更清楚的理解。

### 2. [学会学习](./learning/index.md)

**适合谁：** 明明花了很多时间学习，但总觉得乱、散、累的人。

**你能获得什么：** 重建自己的学习系统，包括输入、方法、复盘与精力节奏。

### 3. [沟通与协作](./communication/index.md)

**适合谁：** 想把表达、关系与团队合作做得更顺的人。

**你能获得什么：** 更清晰地理解如何沟通、协作、处理关系和冲突。

### 4. [工具与系统](./tools/index.md)

**适合谁：** 经常被数字环境、资料管理、工具折腾拖慢节奏的人。

**你能获得什么：** 建立更稳定的数字基础与个人工作流。

### 5. [成长与规划](./growth/index.md)

**适合谁：** 开始意识到财务、健康、机会选择这些长期议题同样重要的人。

**你能获得什么：** 更长期地理解大学生活该如何持续运行，而不是只靠短期爆发。

## 推荐你怎么进入这一部分

### 如果你完全不知道从哪块开始

优先顺序建议是：

1. [认知与心智](./mindset/index.md)
2. [学会学习](./learning/index.md)
3. [工具与系统](./tools/index.md)

这是当前最稳的一条“先修底盘”路线。

### 如果你最想解决“效率和状态”问题

建议先看：

1. [学会学习](./learning/index.md)
2. [成长与规划](./growth/index.md)

### 如果你最想解决“做事和协作”问题

建议先看：

1. [沟通与协作](./communication/index.md)
2. [工具与系统](./tools/index.md)

## 和主线的关系是什么

《第零点五课堂》不是为了替代主线，而是为了给主线提供补给。

如果你还没读过 [核心原则：构建你的个人决策系统](../growth-general-course/01-the-zero-course/the-core.md)，建议先去看那一页。它会帮助你理解：为什么这些能力模块最终都服务于“更好地做判断，并把判断变成行动”。

如果你已经有了基本框架，再回到这里按主题补能力，体验会更好。
