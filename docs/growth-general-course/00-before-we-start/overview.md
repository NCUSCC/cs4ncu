# 全站导览与官方推荐路径

如果你是第一次来到这里，可以把这一页当作本站的“地图 + 导航台”。

它会帮你快速回答 4 个问题：

1. 这是什么项目？
2. 这站内容大致分成哪几块？
3. 我这种读者应该从哪里开始？
4. 现在最值得优先读的官方路径有哪些？

!!! tip "如果你只想立刻开始"
    - 想从最稳妥的起点开始：先读 [《第负一课：先别慌，我们聊聊》](./prologue-the-start.md)
    - 想直接进入核心方法论：去看 [《核心原则》](../01-the-zero-course/the-core.md)
    - 想按主题挑一条路线：直接跳到下方的[官方推荐路径](#官方推荐路径)

## 本站的 4 大板块

### 1. 开始之前：帮助你找准起点

这一部分不是知识堆砌，而是“进入本站前的缓冲区”。

你会在这里看到：

- [《第负一课：先别慌，我们聊聊》](./prologue-the-start.md)：适合刚进站、刚入学、刚陷入焦虑时先读
- 当前这页“全站导览”：适合想先看全局、按路线阅读的人

如果你现在最需要的是一个不慌乱的开始，请从这里起步。

### 2. 寻路通识课：本站最核心的方法论主线

这是本站当前最应该优先阅读的主体内容。

它围绕一个核心问题展开：**普通大学生，如何在不确定里建立自己的判断与行动系统。**

核心入口包括：

- [《核心原则：构建你的个人决策系统》](../01-the-zero-course/the-core.md)
- [《完整课程导览》](../01-the-zero-course/index.md)
- 第一部分：决策的基础
- 第二部分：决策的依据
- 第三部分：决策的实践

如果你不知道该先想什么、先学什么、先做什么，这一块就是默认主路径。

### 3. 第零点五课堂：按主题补齐底层能力

这部分像一个不断扩展的能力模块区，覆盖那些学校往往讲得太晚、太散、或者根本不会系统讲的内容。

目前包含 5 个方向：

- [认知与心智](../../skills/mindset/index.md)
- [学会学习](../../skills/learning/index.md)
- [沟通与协作](../../skills/communication/index.md)
- [工具与系统](../../skills/tools/index.md)
- [成长与规划](../../skills/growth/index.md)

如果你已经有一个大方向，只想补某项能力，可以从这里按需进入。

### 4. 社区与共建 / 昌大专属

这两块承担的是不同职责：

- [社区与共建](../../community/our-story.md)：适合想理解项目理念、参与共建、或看看社区氛围的人
- [昌大专属](../../ncu-exclusive/index.md)：适合南昌大学同学查阅本校场景下的经验与入口信息

!!! note "关于内容边界"
    本站正在持续建设中。我们当前优先保证高曝光入口页、核心路径和成熟内容可稳定阅读；部分专题仍在补完中，因此你会看到一些区域还在逐步充实。

## 你属于哪一类读者？

### 如果你是第一次来的新读者

建议顺序：

1. [第负一课：先别慌，我们聊聊](./prologue-the-start.md)
2. [核心原则：构建你的个人决策系统](../01-the-zero-course/the-core.md)
3. [完整课程导览](../01-the-zero-course/index.md)

适合你，如果你现在最需要的是：

- 搞清楚这个站到底在讲什么
- 先建立一个不慌乱的判断框架
- 不想一上来就被大量页面淹没

### 如果你已经有困惑，但希望系统思考

建议从 [本科生通识第零课](../01-the-zero-course/index.md) 开始，按“向内看 → 向外看 → 去行动”的顺序推进。

适合你，如果你正在面对：

- 专业选择、方向迷茫
- 信息太多，不知道怎么判断
- 想从“听别人建议”切换到“自己做决策”

### 如果你已经有明确问题，只想补一个能力点

可以直接进入 [第零点五课堂](../../skills/index.md)，按模块选读。

适合你，如果你现在更想解决的是：

- 学习效率
- 沟通协作
- 工具使用
- 成长规划

### 如果你想先了解这个项目是否值得信任

建议先读：

1. [我们的初心](../../community/our-story.md)
2. [打卡教程](../../community/how-to-check-in.md)
3. [路友打卡墙](../../community/contributors.md)
4. [贡献流程](../../community/contributing/how-to-contribute.md)

适合你，如果你关心的是：

- 这个项目到底在做什么
- 它和常见经验贴有什么不同
- 如果认同理念，可以怎样参与

## 官方推荐路径

以下是当前第一批官方主推路线。它们只使用本站现阶段相对成熟、可连续阅读的内容，不会故意把你带进明显空白页。

### 路径一：新读者起步路径

**适合谁：** 第一次来到本站、刚入学、最近很乱、需要先找到一个稳定起点的人。

**你能获得什么：** 先安顿情绪，再理解本站的核心方法论，并知道后续该怎么继续读。

1. [首页](../../index.md)
2. [第负一课：先别慌，我们聊聊](./prologue-the-start.md)
3. [核心原则：构建你的个人决策系统](../01-the-zero-course/the-core.md)
4. [完整课程导览](../01-the-zero-course/index.md)

### 路径二：决策与自我认知路径

**适合谁：** 对专业、方向、选择感到卡住，想先把“我是谁、我该怎么判断”想清楚的人。

**你能获得什么：** 建立一个基础决策框架，并把自我认知、思维模式和现实测试串起来。

1. [核心原则：构建你的个人决策系统](../01-the-zero-course/the-core.md)
2. [第一部分：决策的基础](../01-the-zero-course/part1/index.md)
3. [第一章：思维模式转换](../01-the-zero-course/part1/ch1-mindset.md)
4. [第二章：自我认知方法](../01-the-zero-course/part1/ch2-the-self.md)
5. [第六章：低成本实践与验证](../01-the-zero-course/part3/ch6-the-test.md)

### 路径三：学习系统重建路径

**适合谁：** 明明很努力，但总觉得学得乱、记不住、精力不够的人。

**你能获得什么：** 重新搭建自己的学习输入、学习策略与精力管理系统。

1. [第四章：信息获取入门](../01-the-zero-course/part2/ch4-info-gathering.md)
2. [成为学霸的终极秘诀——掌握「元学习」](../../skills/learning/meta/meta-learning.md)
3. [精力管理](../../skills/learning/energy/energy-management.md)

### 路径四：从读者到参与者路径

**适合谁：** 读完后认同项目理念，想进一步围观社区、尝试参与开源的人。

**你能获得什么：** 了解项目边界、认识社区氛围，并找到第一次参与的最低门槛入口。

1. [我们的初心](../../community/our-story.md)
2. [打卡教程](../../community/how-to-check-in.md)
3. [路友打卡墙](../../community/contributors.md)
4. [贡献流程](../../community/contributing/how-to-contribute.md)
