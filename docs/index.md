# 寻路之南

*写给普通人的大学成长指南*

如果你第一次来到这里，可以先记住一句话：**这是一个写给普通大学生的开源成长指南。**

它不试图给你一份万能答案，而是想帮你在信息混乱、选择很多、又常常缺少方向感的时候，先建立自己的判断和行动系统。

## 这是什么项目

寻路之南是一个由普通本科生发起、持续共建中的开源项目。

我们想解决的，不是“怎么复制少数精英样本的成功轨迹”，而是一个更普遍的问题：

**当你没有现成标准答案时，普通大学生怎样一步步完成自我认知、信息判断和现实行动。**

所以这里不会只堆经验贴，也不会把成长理解成单一赛道上的竞速。我们更关注的是那些更底层的问题：

- 我是谁
- 我该如何做选择
- 我该如何获取和判断信息
- 我怎样用低成本方式开始实践

## 一个更简短的故事版本

我们做这个项目，是因为发现大学里最不缺的是碎片化建议，最缺的是一套真正适合普通学生的底层方法。

它不是鸡汤，也不是学校官网替代品，更不是只展示精英样本的经验陈列馆。

它更像一份还在持续完善的公共地图：先帮你找到起点，再陪你一点点把路走清楚。

如果你想看完整版本，可以继续读：[我们的初心](./community/our-story.md)。
