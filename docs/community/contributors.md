# 寻路人打卡墙

这里记录着每一位来过这里、愿意留下足迹的人。

它不是成绩榜，也不是资历榜，而是一面很朴素的“第一步纪念墙”：提醒后来者，**开源参与不一定要从很大的事开始，你完全可以先从一次小而完整的贡献做起。**

如果你是第一次来到这里，建议按这个顺序使用这几页：

1. 先读 [我们的初心](./our-story.md)，了解这个项目为什么存在
2. 再看 [打卡指南：完成你的第一次贡献](./how-to-check-in.md)，按步骤走完第一次 PR
3. 回到这面墙，看看大家是怎样留下第一句话的
4. 如果你还想继续参与，再去看 [贡献流程](./contributing/how-to-contribute.md)

---

## 这面墙的意义是什么

很多人第一次接触开源时，最大的障碍不是技术本身，而是：

- 不知道从哪开始
- 害怕把流程搞错
- 觉得“自己现在还不够格参与”

这面墙存在的目的，就是把第一次参与的门槛降到足够低。

你不需要一开始就写长文、修复杂 bug、或者理解完整仓库结构。你只需要完成一次小但完整的协作流程，就已经迈出了很重要的一步。

!!! tip "如果你也想留下自己的足迹"
    请先阅读 [打卡指南：完成你的第一次贡献](./how-to-check-in.md)。
