# 友联与推荐

这一页不是主入口，而是一份补充性的“同行者清单”。

当你已经理解了寻路之南在做什么，也愿意继续探索更多同类项目时，这里可以给你一些额外的方向。

---

## 为什么有这页

我们并不认为一个项目就能覆盖普通大学生成长中的所有问题。

恰恰相反，很多值得看的内容，本来就分散在不同的社区、站点和共建项目里。把这些同样认真、同样长期主义的同行者整理出来，一方面是在表达感谢，另一方面也能帮助读者获得更广的视野。

所以，这页的职责不是替代本站主线，而是：

- 给想继续扩展阅读的人提供补充入口
- 给认同这种共建方式的人展示更多同行项目
- 为项目之间的互相引用和连接留下空间

---

## 推荐项目

### [Ac-Wiki](https://ac-wiki.org/)：大学生的百科全书

一个由大学生社区共建的综合性知识库，涵盖校园生活、学术资源、成长通道、通识技能等多个方面。

它与寻路之南的关系，不是“谁替代谁”，而更像是两种不同侧重点的互补：

- 寻路之南更强调普通大学生的成长方法、判断框架与行动路径
- Ac-Wiki 更像一份覆盖面更广的大学生知识入口

如果你想在本站之外继续扩展阅读，这是一个很好的下一站。

**[:octicons-link-external-16: 访问 Ac-Wiki](https://ac-wiki.org/)**

## 如果你想添加友联

如果你有与“寻路之南”理念相近的项目或资源，欢迎通过 Pull Request 的方式添加友联。

我们更欢迎这样的项目：

- 面向普通学生，而不是只服务于极少数样本
- 内容真实、长期可维护
- 愿意把经验整理成可被后来者复用的公共资源

!!! note "友联说明"
    本页面的所有链接都属于推荐性质。请在使用任何外部资源前，自行判断其适用性和可靠性。
