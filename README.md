## 这是什么项目

**寻路之南是一份写给普通大学生的开源成长指南。**

它想解决的，不是“怎么复制少数精英样本的成功路线”，而是一个更常见也更现实的问题：

- 当你没有现成标准答案时，怎样理解自己？
- 面对大量信息和建议时，怎样做判断？
- 在迷茫、不确定和资源有限的情况下，怎样一步步开始行动？

所以，这里不会只做经验贴堆叠，也不会把项目做成单纯展示“成功案例”的橱窗。我们更关心的是：**普通学生如何建立自己的判断与行动系统。**

## 当前最推荐的 4 条阅读路径

### 1. 新读者起步路径

**适合谁：** 第一次接触项目、刚入学、最近比较乱、需要一个稳定起点的人。

**读完你能获得什么：** 先安顿情绪，再理解本站主线和后续阅读方式。

- 首页
- 第负一课：先别慌，我们聊聊
- 核心原则：构建你的个人决策系统
- 完整课程导览

### 2. 决策与自我认知路径

**适合谁：** 正在专业、方向、选择上反复摇摆的人。

**读完你能获得什么：** 一个更清晰的自我认知和决策框架。

- 核心原则：构建你的个人决策系统
- 第一部分：决策的基础
- 第一章：思维模式转换
- 第二章：自我认知方法
- 第六章：低成本实践与验证

### 3. 学习系统重建路径

**适合谁：** 明明花了很多时间学习，但总觉得乱、散、累的人。

**读完你能获得什么：** 一个关于信息输入、学习方法和精力管理的学习系统雏形。

- 第四章：信息获取入门
- 元学习
- 精力管理

### 4. 从读者到参与者路径

**适合谁：** 想先理解项目、再看看要不要参与共建的人。

**读完你能获得什么：** 理解项目边界、社区氛围和参与入口。

- [打卡教程](https://cs4ncu.space/community/how-to-check-in/)

| **社区与共建 / 昌大专属** | 前者负责项目故事与参与入口，后者负责南昌大学场景下的经验入口。 |

## 这不是一个什么项目

为了避免误解，我们也想把边界说清楚：

- **这不是鸡汤项目**：我们希望内容能帮助人理解问题和推进下一步，而不只是短暂被鼓舞。
- **这不是学校官网替代品**：我们不替代通知系统，而是帮助普通学生理解制度、资源和机会。
- **这不是只写精英样本的经验陈列馆**：我们更关心普通起点下可复用、可实践的成长方法。

如果你想看完整版本的项目故事，可以阅读：

- [我们的初心](https://cs4ncu.space/community/our-story/)

## 本地开发

如果你希望在本地运行或修改站点：

1. 安装 [Git](https://git-scm.com/)
2. 安装 [uv](https://github.com/astral-sh/uv#installation)
3. 克隆项目并进入目录

```bash
git clone https://github.com/NCUSCC/cs4ncu.git
cd cs4ncu
```

4. 同步环境

```bash
uv sync
```

5. 启动本地预览

```bash
uv run mkdocs serve
```

然后在浏览器打开 `http://127.0.0.1:8000`。
